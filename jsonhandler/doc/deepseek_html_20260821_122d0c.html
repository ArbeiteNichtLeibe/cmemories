🚀 Fluxo de Inicialização

  1. main.cpp (servidor principal)
    • Inicializa MemoryManagerThread com X GB (ex.: 20 GB)
    • Inicializa FakeRedis com redis.initialize(&mm, 0, ...)
    • Chama JSONStart::init(&mm, &redis, false, errBuf, sizeof(errBuf))
  2. json_start.cpp
    • Inicializa JsonGenerator (singleton) com gen->init(mm, redis, ...)
      • Aloca 256 MB da arena (token 0)
      • Chama start_template para estruturar a memória com cabeçalho e slots
      • Carrega templates padrão (se houver)
    • Adiciona um template de teste (ex.: usuario_teste com placeholders <nome> e <senha>)
    • Executa um teste completo:
      • Cria requisição JSON: {"template":"usuario_teste","dados":{"nome":"Maria","senha":"123456"}}
      • Grava no Redis via redis->set(...)
      • Chama JSONWorker::processRequest(requestId, mm, redis, &resultId, ...)
      • Lê o resultado do Redis e exibe
      • Limpa as chaves
  3. O sistema entra no loop principal (aguarda Ctrl+C).

📝 Formato dos Templates

Os templates são strings JSON que contêm placeholders no formato <nome_do_campo>.

Exemplo de template:

{
  "nome": "<nome>",
  "senha": "<senha>"
}

Os placeholders serão substituídos pelos valores fornecidos no campo "dados" da requisição.

📌 Convenção

Placeholders usam <campo> onde campo é o nome da chave no objeto dados.

Exemplo: <nome> será substituído pelo valor de "nome" em dados.

Isso segue a especificação recipejson.md que define tipos como <string>, <int>, etc., mas aqui usamos nomes de campos para mapeamento direto.

📨 Enviando uma Requisição

Para gerar um JSON, você deve armazenar uma requisição no Redis com o seguinte formato:

{
  "template": "usuario_teste",
  "dados": {
    "nome": "Maria",
    "senha": "123456"
  }
}

Essa string JSON deve ser gravada no Redis usando redis->set(requestJson, TTL, ...).

O ID retornado por set é o requestId que você passa para processRequest.

✅ Exemplo de envio (C++)
const char* requestJson = R"({"template":"usuario_teste","dados":{"nome":"Maria","senha":"123456"}})";
int64_t requestId = redis->set(std::string_view(requestJson, strlen(requestJson)), 60000, errBuf, sizeof(errBuf));
if (requestId >= 0) {
    // Processar
    int64_t resultId = -1;
    if (JSONWorker::processRequest(requestId, &g_memory_manager, &redis, &resultId, errBuf, sizeof(errBuf))) {
        // Sucesso – resultado disponível com ID = resultId
    }
}

⚙️ Como Funciona o processRequest

  1. Aloca 100 MB da arena (com token baseado em pthread_self() + aleatório) para processamento temporário.
  2. Lê a requisição do Redis usando requestId.
  3. Faz parsing da requisição JSON (extrai template e dados) – sem usar heap/stack.
  4. Obtém o template da memória do JsonGenerator (via consultar_template).
  5. Aplica substituições: para cada placeholder <campo> no template, busca o valor correspondente no objeto dados e substitui.
  6. Grava o JSON final no Redis com TTL de 3 minutos.
  7. Remove a chave da requisição do Redis.
  8. Libera os 100 MB alocados.
  9. Retorna o ID do resultado (outResultId).

🔍 Obtendo o Resultado

Após chamar processRequest, o resultado estará disponível no Redis com o ID retornado em outResultId.

Para ler o JSON gerado:

char resultBuffer[4096];
if (redis->get(resultId, resultBuffer, sizeof(resultBuffer), errBuf, sizeof(errBuf))) {
    printf("JSON gerado: %s\n", resultBuffer);
} else {
    // erro
}

🧠 Arquitetura de Memória

Zero Heap / Zero Stack
  • Nenhuma alocação dinâmica (new/malloc) – toda memória vem da arena (MemoryManager).
  • Nenhum array local na stack – buffers são alocados na arena.
  • Únicos dados na stack: ponteiros, escalares (int, size_t) e pequenos buffers de erro (256 bytes) – aceitáveis.
ComponenteMemória AlocadaToken/Thread
JsonGenerator256 MB (fixo)0 (main thread)
FakeRedis2 GB0 (main thread)
json_worker_instance (cada processamento)100 MB (temporário)pthread_self() ^ aleatório
Teste de resultado (json_start)1 MB (temporário)pthread_self() ^ 0x12345678

Cada thread só pode ter um empréstimo ativo por vez – por isso usamos tokens diferentes para cada alocação.

📋 Exemplo Completo de Uso no main

#include "json_worker_instance.hpp"
#include "json_start.hpp"
#include "../../memorymanager/include/memory_manager_thread.hpp"
#include "../../fakeredis/include/fake_redis.hpp"

int main() {
    memorymanager::MemoryManagerThread mm;
    mm.init(20); // 20 GB

    FakeRedis::FakeRedis& redis = FakeRedis::FakeRedis::getInstance();
    redis.initialize(&mm, 0, ...);

    if (!JSONStart::init(&mm, &redis, false, errBuf, sizeof(errBuf))) {
        // falha
        return 1;
    }

    // Em algum lugar, ao receber uma requisição:
    const char* req = R"({"template":"usuario_teste","dados":{"nome":"João","senha":"789"}})";
    int64_t reqId = redis.set(std::string_view(req, strlen(req)), 60000, errBuf, sizeof(errBuf));
    if (reqId >= 0) {
        int64_t resId = -1;
        if (JSONWorker::processRequest(reqId, &mm, &redis, &resId, errBuf, sizeof(errBuf))) {
            // JSON gerado está em resId
            char json[4096];
            if (redis.get(resId, json, sizeof(json), errBuf, sizeof(errBuf))) {
                printf("Resultado: %s\n", json);
            }
            redis.del(resId, ...);
        }
        redis.del(reqId, ...);
    }

    // Loop principal...
    while (true) sleep(1);
    return 0;
}
