🛠️ Adicionar Nova Rota

Para adicionar uma nova rota no servidor, edite o arquivo router.cpp e insira um novo bloco na função route_request. Exemplo:

if (strcmp(req->method, "GET") == 0 && strcmp(req->path, "/minharota") == 0) {
    resp->status_code = 200;
    resp->content_type = "application/json";
    resp->body = "{\"mensagem\":\"Ola, mundo!\"}";
    resp->body_len = strlen(resp->body);
    return true;
}

Depois recompile e reinicie o servidor.
